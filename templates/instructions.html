INTEGRATION ARCHITECTURE GUIDE

Connecting Tableau Dashboard & Story to Flask

Step-by-step documentation on how to publish workbooks to Tableau Public, grab the correct embed URLs, and configure the Flask web routes to render interactive dashboards and stories seamlessly.

STEP 1

Create & Publish Your Workbook to Tableau Public

  1. Open your Formula 1 workbook in Tableau Desktop or Tableau Public Desktop.
  2. Make sure you have:
    • At least one Dashboard tab (e.g., RaceIntelligenceDashboard).
    • At least one Story tab (e.g., ChampionshipNarrativeStory) composed of story points.
  3. In the top menu, navigate to: Server → Tableau Public → Save to Tableau Public As...
  4. Sign in to your free Tableau Public account and name your workbook (e.g., Formula1RaceIntelligence).
  5. Click Save. Tableau will upload the workbook and open it in your default web browser on public.tableau.com.
STEP 2

Obtain the Dashboard and Story Embed Links

On your published workbook page on Tableau Public:

Option A: The Share Button

Click the Share button (3 connected dots icon at the bottom right of the Tableau toolbar). In the dialog:

  • Link: Copies the clean view URL:
    https://public.tableau.com/views/YOUR_WORKBOOK/YOUR_DASHBOARD
  • Embed Code: Copies the full HTML/JavaScript object code snippet.
Option B: Direct Browser URL

You can also copy the URL directly from your browser's address bar when viewing the Dashboard or Story tab:
https://public.tableau.com/views/[WorkbookName]/[DashboardOrStoryName]?:showVizHome=no&:embed=true

STEP 3

Connect the URLs to this Flask Application

You have two convenient methods to apply your links:

Method 1: Live In-Browser Connector (Instant & No Code)

Click the floating Connect Tableau button on the bottom right of any page. Paste your Dashboard URL and Story URL, then click Apply & Connect. The website connects and refreshes immediately!

Method 2: Permanent Configuration in config.py

Open config.py in the project root and update the two constants: 

class Config:
    TABLEAU_DASHBOARD_URL = "https://public.tableau.com/views/YOUR_WORKBOOK/YOUR_DASHBOARD"
    TABLEAU_STORY_URL     = "https://public.tableau.com/views/YOUR_WORKBOOK/YOUR_STORY"
STEP 4

How Embedding API v3 Works in Flask Templates

This application uses Salesforce's modern Tableau Embedding API v3, which provides web components (<tableau-viz>) for clean, responsive integration without messy iframe hacks.

1. Script included in templates/base.html: 
<script type="module" src="https://public.tableau.com/javascripts/api/tableau.embedding.3.latest.min.js"></script>
2. Web Component rendered in templates/dashboard.html: 
<tableau-viz 
    id="tableau-dashboard-viz"
    src="{{ tableau_dashboard_url }}"
    toolbar="bottom"
    device="default"
    hide-tabs="true">
</tableau-viz>
STEP 5

Running Your Application Locally

Execute the launch script or start the Flask development server from your terminal: 

# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the Flask application
python app.py

# 3. Open in your browser:
# http://127.0.0.1:5000
